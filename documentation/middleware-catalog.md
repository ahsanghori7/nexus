# Reusable Middleware Catalog

This file is generated by `scripts/generate_framework_middleware_catalog.php`.
It lists middleware factory methods (public static methods returning `callable`/`Callable`/`Closure`) under `framework/src/**/code/Middleware/**`.

## How to use this

- When implementing a new endpoint, check if a middleware already exists for the task (fetching common entities, ownership checks, REST passthrough, etc.).
- In route files, middleware entries are callables, so you typically add factories like `Rest::fetchDynamic(...)` or `Generic::set(...)` to the `middleware` array.
- If you create new reusable middleware, add it under the appropriate `framework/src/<app>/code/Middleware/` directory and regenerate this catalog.

## Index

- Core utilities: `framework/src/core/code/Middleware/`
- API-specific utilities: `framework/src/api/code/Middleware/`
